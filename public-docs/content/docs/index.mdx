# Welcome to Mocopo

Mocopo is a highly configurable Model Context Protocol (MCP) server implementation that provides a robust foundation for building AI-powered applications with tool execution capabilities.

## 🚀 Key Features

### Core MCP Server
- **Multiple Transport Protocols**: stdio, HTTP, WebSocket
- **Configuration-Driven**: YAML, JSON, or environment variable configuration
- **Extensible Tool System**: Built-in tools and plugin architecture
- **Context Management**: Persistent context across tool calls

### 🔥 Admin API (Production Ready)
- **28 Endpoints**: Complete action management system
- **4 Action Types**: REST, CODE_RUN, O3, DATABASE executors
- **Secret Management**: AES-256-GCM encryption
- **MongoDB Integration**: Async operations with connection pooling
- **Production Security**: Comprehensive encryption and validation

### 🔐 Secure Code Execution
- **Sandboxed Python Execution**: Secure, isolated code execution environment
- **Docker Infrastructure**: Production-ready containerized execution
- **22+ Security Measures**: Non-root execution, read-only filesystem, resource limits

## Quick Start

### Installation

```bash
# Install from local directory (development)
pip install -e .

# Or install from built wheel
pip install mcp-server
```

### Basic Usage

```bash
# Run with stdio transport (default)
mcp-server stdio

# Run with HTTP transport
mcp-server http --host 0.0.0.0 --port 8080

# Run with configuration file
mcp-server --config config.yaml http
```

### Admin API Integration

```python
from fastapi import FastAPI
from mcp.admin.router import admin_router

app = FastAPI()
app.include_router(admin_router, prefix="/admin/api/v1")
```

## Action Types

Mocopo supports four types of actions for different use cases:

### 1. REST Actions
Execute HTTP requests with secret authentication
```json
{
  "name": "github_api",
  "type": "REST",
  "default_config": {
    "url": "https://api.github.com/repos/{owner}/{repo}",
    "method": "GET",
    "headers": {
      "Authorization": "token ${GITHUB_TOKEN}"
    }
  }
}
```

### 2. CODE_RUN Actions
Execute Python code in secure sandbox
```json
{
  "name": "data_processor",
  "type": "CODE_RUN",
  "default_config": {
    "language": "python",
    "code": "output = {'result': sum(input_data.get('numbers', []))}"
  }
}
```
